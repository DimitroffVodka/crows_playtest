# Playing Crows in Foundry

Task-shaped guides for **Refs and players at the table**: how to do a thing, what
you will see, and what to do when it refuses.

This is not a rules reference. The rules live in the MCDM playtest packet — see
the [main README](../../README.md) for where to get it. These pages describe
what *this system* does and how to drive it.

> **A note on honesty.** Where something is unimplemented, broken, or awkward,
> these pages say so rather than describing the version we wish existed. If a
> page and the software disagree, the software is right and the page is a bug —
> please report it.

## Two things worth knowing before anything else

**Coin lives in two places.** `system.currency` on a crow is **loose coin
only**. A Coin Purse is an ordinary Item with its own capacity. If you watch
only the currency field you will think money has vanished when it has merely
moved into a purse. [Money and shopping](money-and-shopping.md) explains it.

**Shared changes go through the Ref.** Players can browse the village and
propose actions. Founding, upgrading, ending a cycle and rolling an event are
committed by the Ref or the designated GM. A proposal is not a reservation, and
nothing has happened until a receipt says so.
